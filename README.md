# لندینگ‌ساز زرپین

ابزاری برای تیم مارکتینگ که بدون کمک تیم فنی، لندینگ کمپین را از سکشن‌های آماده سرهم کند. همه‌چیز از دیزاین سیستم زرپین می‌آید و ابزار اجازه‌ی خروج از آن را نمی‌دهد.

نسخه‌ی آنلاین (با فهرست مشترک لندینگ‌ها): https://claude.ai/artifact/Ch6tdC271gzhbWJ64iY3dQ

## چه کاری می‌شود کرد

- ساختن، تکثیر و حذف لندینگ؛ فهرست لندینگ‌ها در صفحه‌ی اول.
- ۷ نوع سکشن: هیرو، ویژگی‌ها، مراحل، اعداد، تصویر و متن، دعوت به اقدام، سؤال‌های متداول. هدر و فوتر ثابت‌اند.
- برای هر سکشن: انتخاب لی‌اوت از گزینه‌های مجاز، یکی از ۵ رنگ پس‌زمینه، ویرایش متن با سقف کاراکتر، حذف و افزودن فیلدهای اختیاری.
- دکمه‌ها: حداکثر ۲ در هر سکشن؛ یا لینک https (با UTM خودکار) یا رفتن به یک سکشن همین صفحه.
- پیش‌نمایش دسکتاپ و موبایل؛ بررسی خطاها پیش از خروجی.
- خروجی: یک فایل HTML تک‌صفحه‌ای (فونت، لوگو و تصویرها داخل فایل) و فایل پروژه‌ی JSON.

## ذخیره‌سازی

- روی claude.ai: لندینگ‌ها در پایگاه داده‌ی خود صفحه و بین همه‌ی کسانی که به آن دسترسی دارند مشترک است؛ تصویرها در فضای فایل صفحه.
- اگر `landing-builder.html` مستقیم در مرورگر باز شود: لندینگ‌ها فقط در همان مرورگر ذخیره می‌شوند.

## ساختار

| مسیر | چیست |
|---|---|
| `landing-builder.html` | فایل نهایی و قابل اجرا (خروجی ساخت). |
| `src/app.html` | سورس اصلی: CSS، HTML و JS ابزار. |
| `src/font.css` | فونت یکان بخ (base64). |
| `src/icons.js` | آیکون‌های انتخاب‌شده از مجموعه‌ی آیکون زرپین. |
| `src/logo-*.txt` | لوگوهای زرپین (data URI). |
| `build.pl` | سرهم کردن `src/` در `landing-builder.html`. |

## ساخت

```bash
perl build.pl
```

بعد از هر تغییر در `src/app.html` این دستور را اجرا کنید تا `landing-builder.html` به‌روز شود.

## کارهای باز

- آدرس‌های لینک دکمه‌های لندینگ نمونه خالی‌اند و باید آدرس واقعی سایت/اپ زرپین جایگزین شود.
